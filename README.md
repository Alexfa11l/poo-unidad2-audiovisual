Proyecto desarrollado para la Universidad Politécnica Salesiana en la materia de Programación Orientada a Objetos. Su objetivo principal es aplicar conceptos avanzados de POO como herencia, polimorfismo, asociación, agregación y composición mediante la expansión de un sistema de gestión de contenidos audiovisuales en Java.

El sistema permite registrar y estructurar diferentes tipos de medios. Como parte del desarrollo, incluimos las clases y relaciones de la segunda etapa con actores, temporadas e investigadores. Además, añadimos por iniciativa propia las subclases de audiolibro y podcast heredando de la clase principal, junto con un sistema funcional polimórfico en consola.

Para clonar y ejecutar el proyecto:
1. Copia la URL del repositorio y clónalo usando tu terminal con el comando:
   git clone https://github.com/Alexfa11l/poo-unidad2-audiovisual.git
2. Abre Eclipse IDE, selecciona File y Open Projects from File System, y busca la carpeta del proyecto.
3. Navega hasta src/poo/PruebaAudioVisual.java, haz clic derecho y selecciona Run As > Java Application.

Como mejoras adicionales e implementación técnica, el repositorio cuenta con un control estricto de versiones estructurado en commits evolutivos ordenados por cada etapa y una documentación clara para facilitar su revisión.
